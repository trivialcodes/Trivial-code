Unit 1

Variables, Memory & Primitive Types

Python is dynamically typed and garbage collected. Variables are not memory boxes; they are labels pointing to objects in heap memory.

Everything is an Object

When you execute x = 5, Python creates an integer object 5 in heap memory, and binds the name x to that object.

# Reference Aliasing Demo
a = [1, 2, 3]
b = a
b.append(4)
print(a)  # Output: [1, 2, 3, 4] -> Both names point to the SAME list!

Unit 2

Control Flow & Iteration

Governing the execution path using boolean predicates, short-circuit evaluation, and structured looping constructs.

Truthy and Falsy Values

In Python, conditions do not strictly require booleans. Python evaluates objects based on truthiness:

Always Falsy in Python:

None, False, zero of any numeric type (0, 0.0), empty sequences ("", [], ()), empty mappings ({}).

Loop Control Statements

break
Immediately terminates the nearest enclosing loop and resumes execution at the next outer statement.
continue
Skips the remainder of the current loop iteration and jumps immediately to the next evaluation step.

Unit 4

Functions & Scope Resolution

The LEGB rule determines how Python searches for variable bindings.

The LEGB Scope Rule

L — Local: Defined inside the current function.

E — Enclosing: Defined in any enclosing function closures.

G — Global: Defined at the top level of the current module file.

B — Built-in: Pre-assigned identifiers (e.g. len, range, print).

Unit 5

Object-Oriented Programming (OOP)

Encapsulation, state initialization with __init__, and instance methods.

Dunder Methods

Double-underscore methods allow Python objects to hook into native language syntax:

class Account:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def __str__(self):
        return f"Account({self.owner}, ${self.balance})"

acc = Account("Taylor", 150)
print(acc)  # Calls __str__ -> "Account(Taylor, $150)"
